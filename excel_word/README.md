# Word 表格 ⇄ Excel 双向同步工具

把 Word 报告/附注里的**全部表格**导出到 Excel，建立**书签定位**，并在 Excel 改完数据后**原样回写**到 Word（保留字体、字号、边框、对齐、合并单元格），支持在 Excel 中**增删行、增删列**。Word 后续新增的表格、标注和占位符用「增量导出」追加登记，既有行号、编号与公式位置不变。纯 Python 实现，不依赖 Office 宏或 COM。

## 一、目录结构

```
excel_word\
├─ 1-导出表格到Excel.py      # 入口：Word → Excel（含书签、跳转链接）
├─ 2-Excel同步到Word.py      # 入口：Excel → Word（含增删行、增删列，同步 T/XT 表）
├─ 3-重建书签.py             # 入口：只修书签与正文遗留文字，不动数据
├─ 4-删除空白表格.py          # 入口：扫描/删除空白表（整表全空/仅表头有字），可连表标题
├─ 5-导出标注.py              # 入口：把 Word 高亮标记导出到「链接标注」工作表
├─ 6-同步标注.py              # 入口：把「链接标注」里填写的内容同步回 Word
├─ word_excel_sync.py       # 兼容入口：export / bookmark / writeback 子命令（需显式传文件名）
├─ wesync\                  # 核心包
│  ├─ config.py             常量与正则（工作表名、书签前缀、字体配色、各种上限）
│  ├─ errors.py / console.py 业务异常、中文日志与用法提示
│  ├─ fsops.py               路径解析、备份、占用检测、自动识别同目录 docx
│  ├─ valuefmt.py            数字↔文本、显示文本、列宽估算、轻量公式求值
│  ├─ api.py                 对外稳定接口：run_export / run_incremental_export / run_bookmark / run_writeback 等
│  ├─ docx_marks.py          高亮标记识别、整段书签锚点与写回（替换文字/加链接/去色）
│  ├─ docx_blank.py          空白表识别（整表全空/仅表头有字）、表标题识别与按选择删除
│  ├─ excel_marks.py         「链接标注」工作表的生成与回读
│  ├─ docx_grid.py           Word 表格网格：gridSpan/vMerge、合并区、边框、对齐、文本
│  ├─ docx_meta.py           标题层级、表名与章节识别、表块信息汇总
│  ├─ docx_bookmarks.py      书签读写、Table_ 命名与旧书签迁移、遗留文字/超链接域清理
│  ├─ docx_edit.py           单元格写入（保留 run 格式、多段、空值）
│  ├─ docx_rows.py           行结构同步（增行/删行）
│  ├─ docx_columns.py        列结构同步（列位匹配、插入/删除列、合并区扩展收缩）
│  ├─ docx_newtable.py       删除表格恢复：按 Excel 保留内容重建表格
│  ├─ excel_export.py        生成工作簿（堆叠表块、样式、链接、定义名称）
│  ├─ excel_blocks.py        解析工作簿（T/XT 表块、锚点元数据、定义名称刷新）
│  ├─ sort_rules.py          按金额列排序：「排序：」设置读写、数据行重排、导出按书签沿用
│  ├─ commands\              export / bookmark / writeback / marks / blank 等子命令实现
│  ├─ gui\                   图形界面（PySide6）：主窗口、主题、组件、六个功能页
│  └─ cli.py                 子命令参数与 main()（也可 python -m wesync）
├─ _backup\                 每次写盘前的自动备份
└─ requirements.txt
```

依赖方向单向无环，改动某一块不会牵动其它层；每个模块 60～260 行，便于定位与排错。

```powershell
..\.venv\Scripts\python.exe -c "import docx, openpyxl, lxml; print('依赖正常')"
```

> 说明：在本目录（`excel_word\`）下执行命令时，用 `..\.venv\Scripts\python.exe` 即可调用根目录共享解释器；下一个新功能放在工具箱根目录下另开子目录，直接复用同一个 `..\.venv`。

其他机器复现（在工具箱根目录执行，需先安装 uv）：

```powershell
uv sync --extra exe
```

## 三、用法

三个入口脚本都可以**不传文件名**：会自动使用当前目录下唯一的 `.docx`（有多个或没有时给出中文提示）。

```powershell
# 1) 导出：Word → Excel（会按当前 Word 重新生成工作簿，覆盖前自动备份）
..\.venv\Scripts\python.exe "1-导出表格到Excel.py"
..\.venv\Scripts\python.exe "1-导出表格到Excel.py" --dry-run          # 只看将导出什么
..\.venv\Scripts\python.exe "1-导出表格到Excel.py" "报告.docx"        # 指定文件

# 2) 回写：Excel → Word（含增删行、增删列；同时同步「表格汇总」和「新增表格」）
..\.venv\Scripts\python.exe "2-Excel同步到Word.py" --dry-run          # 预演，列出要改的单元格
..\.venv\Scripts\python.exe "2-Excel同步到Word.py"                    # 正式回写（先自动备份）

# 3) 书签：只处理书签与正文遗留文字，不动任何数据
..\.venv\Scripts\python.exe "3-重建书签.py"

# 3.5) 空白表：默认只扫描列候选；--pick 编号 或 --all 明确选择后才删除
..\.venv\Scripts\python.exe "4-删除空白表格.py"                     # 只扫描，不删
..\.venv\Scripts\python.exe "4-删除空白表格.py" --pick 1,3          # 删候选1、3（连表标题）
..\.venv\Scripts\python.exe "4-删除空白表格.py" --all --keep-caption # 删全部候选，保留标题
..\.venv\Scripts\python.exe "4-删除空白表格.py" --pick 1 --reversible # 可逆删除：Excel 表块保留待恢复
..\.venv\Scripts\python.exe "4-删除空白表格.py" --restore all        # 恢复全部已可逆删除的表

# 4) 链接标注：把 Word 高亮标记导出到工作簿的「链接标注」工作表
..\.venv\Scripts\python.exe "5-导出标注.py"

# 5) 把「链接标注」里填好的新内容/链接地址同步回 Word（先预演更稳妥）
..\.venv\Scripts\python.exe "6-同步标注.py" --dry-run
..\.venv\Scripts\python.exe "6-同步标注.py"

# 6) 正文占位符：按 Word 的 {字段名} 给工作簿「正文信息」表补骨架 / 填值写回
..\.venv\Scripts\python.exe -m wesync placeholders      "报告.docx"
..\.venv\Scripts\python.exe -m wesync placeholders-sync "报告.docx" --dry-run

# 7) 增量导出：只追加 Word 中尚未登记的新表格/标注/占位符，不改既有行
..\.venv\Scripts\python.exe -m wesync incremental-export "报告.docx" --dry-run
..\.venv\Scripts\python.exe -m wesync incremental-export "报告.docx"

# 8) 回写时组合同步内容（默认只同步表格；可叠加标注/占位符）
..\.venv\Scripts\python.exe -m wesync writeback "报告.docx" --with-marks --with-placeholders
```

等价的其它调用方式：

```powershell
..\.venv\Scripts\python.exe -m wesync writeback "报告.docx" --dry-run     # 以包方式运行
..\.venv\Scripts\python.exe word_excel_sync.py writeback "报告.docx"      # 兼容入口（必须带文件名）
```

通用参数：`--excel <路径>`（默认同目录 `<主名>_表格数据.xlsx`）、`--dry-run`、`--force`（跳过占用检查）、`--no-excel-links`（不在 Excel 中写跳转链接）。

## 四、图形界面

图形界面是**工具箱全局界面**，入口在工具箱根目录：双击 **`审计工具箱.pyw`**（不会弹黑色控制台窗口），或者：

```powershell
..\.venv\Scripts\python.exe ..\审计工具箱.pyw
..\.venv\Scripts\python.exe -m wesync.gui
```

界面结构：**左侧功能导航 + 中间页面 + 右侧可隐藏日志 + 状态栏**（PySide6 / Qt6）。

* 顶部文件条：选择 Word 文件、指定/恢复默认工作簿名、一键打开所在文件夹；打开界面时会自动识别同目录唯一的 docx，并记住上次使用的文件（配置写在项目根 `.wesync_ui.json`，不进系统目录）。
* 八个功能页：**创建Excel**、**同步Word**、**标注与占位**、**书签工具**、**空白表格**、**批量同步**、**备份与回滚**、**使用说明**；写盘类页面都有预演/确认机制，点“开始执行”会先弹确认框（显示操作名与目标文件），确认后才写盘。
* **使用说明页**：完整说明书已内置，支持章节导航与关键词搜索；任意页面按 F1 可快速打开，无需联网。
* **标注与占位页含两个 tab**：「链接标注」（高亮标记导出/预演/同步 + 保留高亮勾选）与「正文占位符」（按 Word 的 `{字段名}` 导出/刷新「正文信息」填写骨架、预演/同步写回；骨架保留已填值，与「模板生成」共用同一张表）。
* **空白表格页含三个 tab**：「删除空白表格」（扫描→逐表勾选→确认删除，可逆删除勾选、连表标题一起删）、「恢复已删除表格」（刷新恢复清单→勾选→按原位置恢复）与「批量删除空表」（多份报告一次扫描、按报告分组勾选删除，口径与单文件一致，默认可逆）。
* **批量同步页含两个 tab**：「多报告批量同步」（每份报告配同名工作簿逐个同步，单份失败只跳过该份；**同步内容三勾选：表格/标注/占位符任意组合**，默认只勾表格）与「模板生成」（单模板/多模板切换；**同步内容三勾选：表格/标注/占位符任意组合**，默认勾表格＋占位符；多模板时 Excel 清单第三列指定所属模板编号分组；每个 Excel 同步到模板副本生成新 Word，模板原件与源 Excel 不改动；支持模板正文 `{字段名}` 占位符按工作簿「正文信息」表替换）。详见第十五节。
* **同步页含三个 tab**：「同步回写」（**同步内容三勾选：表格/标注/占位符任意组合**，默认只勾表格；勾标注时显示「同步标注后保留高亮」勾选；另有强制/备份/改动清单/删除✕行四个勾选 + 仅预演/开始同步；备份/改动清单/删除✕行只作用于表格）、「排序设置」（选表→选金额列→选方向→保存；设置写进工作簿锚点行「排序：」元数据，随文件保存，每次同步自动应用，详见第十四节）、「差异比对」（只读逐格差异表 + 导出差异表）。
* **创建Excel 页「重新判定✓/✕」按钮**：按工作簿当前内容重判 B 列 表头/✓/✕（只改标记、不改数据、不改 Word；「已删」行保持原样；旧布局工作簿提示先重新导出）。命令行 `rejudge` 子命令同口径。
* 工作簿不存在时（例如刚删掉或换机器），“同步到 Word”会提示“未找到工作簿，是否现在导出生成？”，确认后自动先导出再继续同步。
* **创建Excel 页「增量导出」按钮**：只追加 Word 中尚未登记的新表格、高亮标注和正文占位符；新表进入「新增表格」并编号 XT01、XT02…，新标注进入「链接标注」并编号 XM01、XM02…，新占位符追加到「正文信息」。既有行、编号、填写值与公式位置不变；无新增时两个文件都不改写。旧版「追加新表块」已停用。
* 执行在后台线程进行，日志实时刷新（成功/警告/错误分色），执行期间按钮自动禁用；结束后弹摘要，失败弹错误提示。
* 右侧日志区支持 **清空 / 复制全部 / 保存为文件 / 自动滚动**，可用「隐藏」按钮或状态栏「隐藏日志/显示日志」按钮收起；显隐状态与宽度记入偏好，下次启动恢复。
* 新增功能：本包内新页面继承 `wesync/gui/pages.BasePage` 并调用 `register_page()`；其它功能子目录在自己的 `gui_pages.py` 里注册，启动器自动发现加载（见根《功能规划与文件布局.md》第六节）。
* 界面依赖 PySide6-Essentials（见根 `pyproject.toml`），不改变命令行行为。

## 五、书签与定位

* 每张表一个书签，新书签命名为 `Table_` + 4 位随机大写字母/数字（如 `Table_3K9Q`），创建后固定不变；早期 `CPAH_…` 名字沿用工作簿记录继续使用，旧 `TBL_01…` 会自动清理重建。
* **书签覆盖整张表**（起点在首行首格、终点在末行末格）：在 Excel 点“→定位Word表”会直接选中整张表格，而不是只停在标题行。
* **按内容重新对齐**：书签工具（`3-重建书签.py`）会用「列数+行数+首行+首列」内容签名把工作簿表块与 Word 表格 1:1 配对（**完全一致才动**），因此表被删除、顺序变动、书签锚错都能自动纠正；无法对齐的表会列为“未对齐”并提示重新导出。
* 旧的 `TBL_01…` 书签会在运行时**自动清理重建**；只删除本工具自己创建的旧书签，不动其它书签。
* Excel 每个表块锚点行的 E 列是 `→定位Word表` 超链接，点击即打开 Word **选中对应整张表格**；书签名记录在同行的 D 列。
* Word 侧不再写入任何超链接：早期版本的 `〔→Excel〕` 文字与超链接域会在运行时自动清除。

## 六、Excel 工作簿约定

**导出固定生成三个工作表**：`表格汇总`（下叙表块结构；Word 无表格时为空表）、`链接标注`、`正文信息`。只要表格/标注/占位符存在一种就会导出填充，都没有时三张空表也照建；没有任何表格的 Word 也可以导出（用于标注、占位符、模板生成）。

`表格汇总` 中各表垂直堆叠：

* **A 列 = 表编号**（`T01`…）：识别表块边界，请勿修改。
* **B 列 = 行标记**：表头行写「表头」；其余行首列不参与判断，其他任何一列有内容（含公式、`—` 占位）=✓、全空=✕；勾选「删除✕行」同步后被删行记「已删」（改回✓可恢复）。标记只作判定与删除依据，手工改✓/✕不影响数据同步。
* 每块首行是**锚点行**（C 表名与章节、D 书签、E 跳转链接、F 列数），其下为表格网格，自 **C 列**开始。
* **旧布局自动兼容**：1.9.0 之前导出的工作簿（锚点 B 表名/C 书签/D 链接/E 列数、网格自 B 列、无标记列）仍可正常同步与排序；「删除✕行」「重新判定」对其不生效并提示重新导出升级。
* 表块内允许 A 列为空但网格有内容的行（在 Excel 里插入行后直接填数据，也能正确归属本表）。
* 数字导出为**真数值**并保留千分位格式（如 `#,##0.00`）；`—`、`——`、纯文本按文本导出；合并单元格、对齐、边框按 Word 还原。
* **回写按 Excel 显示格式输出**（1.10.0）：日期/时间（含 `2026年12月31日` 这类中文年月日格式、带区域前缀的 `[$-804]yyyy"年"m"月"d"日"`）、千分位有无、小数位、百分比、负数括号段、零值段（如 `—`）、会计专用格式（`_ * #,##0.00_ ;…` 含对齐全角/半角填充与 `"-"??` 零值段）都按单元格格式渲染后写回 Word——存储仍是真数值/日期序列值，便于计算；`General` 不加千分位。子集外的格式（如 `[h]:mm` 耗时、科学计数）回退「千分位+小数位」旧口径并按格式警告一次。差异比对、排序、列宽估算、正文占位符取值（「正文信息」表）同口径。「重新判定✓/✕」改按**原始值**有无内容判定（显示为空但值为 0 也算✓）。
* **合计行自动写求和公式**（默认开启）：首列以「合计」开头的行，其数值列导出为 `=SUM(数据区首行:数据区末行)`，在 Excel 改明细后合计自动更新；同步时按公式结果回写 Word（公式求值与回写同口径）。数据区 = 表头之后、合计行之前（表头按 `w:tblHeader` 标记识别，未标记时按首行）；文字列（如备注）与 `—` 占位不写公式。导出页可取消勾选「合计行自动写求和公式」，命令行加 `--no-total-formulas` 关闭。核心实现在 `wesync/excel_totals.py`。
* **覆盖前备份可选**（默认开启）：导出会重建工作簿、并可能改动 Word 书签；默认先把被覆盖的原文件备份到同目录 `_backup/`。导出页取消勾选「覆盖前备份原文件到 _backup」或命令行加 `--no-backup` 则直接覆盖、不留底（不可回滚），确认弹窗会相应提示。
* **表格内排除**：表格单元格里的高亮标注与 `{字段名}` 占位符不参与全量导出、增量导出或同步，避免与表格数据写回冲突。表格外的表标题段落仍按正文处理；页眉页脚的正文标注/占位符参与，页眉页脚里的表格排除。
* **高亮口径**：支持直接高亮、字符样式及其 `basedOn` 继承、段落标记高亮；空白高亮不登记，本地 `w:highlight w:val="none"` 可取消样式高亮。不会把底纹、字体颜色、加粗或斜体误判为高亮；样式高亮去色时只给当前 run 加本地 `none`，不修改共享样式。
* **删除✕行（可选，默认关闭）**：同步页勾选「删除✕行」或命令行 `--delete-empty-rows` 后，B 列✕的行连 Word 行一起删除；Excel 该行物理保留、B 列记「已删」（灰字灰底），改回✓再同步即恢复（行内须有内容，整行全空的先填内容）。首列以「合计」开头的行永不删；若某表数据行全为✕，删除时告警：删后只剩表头/合计，恢复时因无数据行可复制格式会跳过该表（需手工补行或从备份回滚）。核心实现在 `wesync/commands/writeback_cmd.py`（过滤✕行后走既有 `align_rows` 增删行）。

## 七、回写规则

* **匹配方式（按书签配对）**：用工作簿每个表块 D 列（旧布局 C 列）记录的书签名（如 `书签：Table_3K9Q`）去 Word 里认表。
  * 书签已迁移成“覆盖整张表”后，直接按**表内书签**匹配；尚未迁移的旧文档继续用“锚点段落 + 紧随其后的表格”配对。两种书签可在同一文档混用，按书签逐项补充配对。
  * 若工作簿 D 列出现**重复书签名**（早期版本曾写脏过），按内容能对上该表的那一块优先，其余跳过并在日志里提示。
* **单表结构对不上只跳过**：列数/表头无法对齐时（例如某块与表根本不是同一张表），只跳过这一张并记 `[跳过] …结构不符…`，其余表继续同步，不再整批中止。该表在同步前留 XML 快照，失败时整表回滚并撤掉对应留痕，不残留部分行列或单元格修改。
* **Word 中已删除的表自动跳过**：某个表块的书签在 Word 里找不到对应表格时，该块**跳过**并在日志里逐条列出（`[跳过] T03 xxx：Word 中已找不到该表格（书签 Table_…，可能已被删除）`），其余表格照常同步，不再因数量不一致而中止。跳过的块不改动 Excel 内容。
* **旧工作簿保护**：若工作簿**一个书签记录都没有**（旧版本或非本工具生成），回写会直接报错并提示“请先用「导出表格到 Excel」重建工作簿”，避免按位置错配写坏数据。
* **导出提醒**：导出前会检查现有工作簿，若其中有表块在 Word 中已找不到对应表格，会提示“有 N 个表块…导出将按当前 Word 重建，这些块会消失”，提醒后仍继续导出。
* **汇总行**：结束时输出 `合计：同步 X 张表（改动 a 个单元格，b 行结构，c 列结构），跳过 Y 张表`。
* **单元格内容**：以 Excel 的“显示文本”为准；Excel 置空 → Word 清空文本但保留格式。
* **格式保护**：只替换文字，保留字体、字号、颜色、段落对齐、单元格宽度/边框/垂直对齐/合并结构。
* **增行/删行**：只作用于表头之后的数据区；新增行以数据区末行为模板（末行为“合计”时插到合计行之前）；删行时日志列出被删行首列内容；“合计”始终保持在末行。
* **增列/删列**：用表头文本自动判定插入或删除位置，匹配度不足时中止并提示；新列克隆相邻列格式，落在表头合并区内会同步扩展（删除时收缩）；**整列空白的新增列在该表忽略**（填入内容即可同步）。
* **公式**：优先取 Excel 缓存结果；缓存丢失时用内置轻量求值处理 `SUM(...)` 与简单四则运算。
* **双文件保存**：Excel 与 Word 先分别序列化到同目录临时文件并重新打开校验，再按顺序替换；第二步替换失败时，第一步自动恢复原文件，避免 Excel 已记「已删」而 Word 未删行的状态分裂。
* **新增表格（XT）**：增量导出的新表永久放在「新增表格」工作表，编号 `XT01`、`XT02`…，按增量发现顺序排列，不按 Word 位置重排；真实 `Table_` 书签用于回写定位。`表格汇总` 与 `新增表格` 一起参与同步、排序、批量、模板生成、空白表可逆删除/恢复。旧版 `书签：新增` 表块已停用并会明确跳过。

**同步后表格没更新或看起来像“丢失”**：先看日志 `[跳过]`，区分整表不见与表内更新缺失。回写主链路不会删除整张表；整表不见优先排查「删除空白表格」、外部删表和历史回滚。正式同步前勾选备份，先「仅预演」和「差异比对」；已发生异常时关闭 Word/Excel，恢复同一次操作前的 Word 与 Excel，不要只恢复一个或直接重新导出覆盖工作簿。

## 八、备份与安全

* 每次写文件前把原文件复制到 `_backup\`，命名 `<原名>.<时间戳>.bak.<扩展名>`。
* 检测到文件被 Word/Excel 占用时提示先关闭并退出，不会写坏文件；残留的 `~$` 锁文件只给警告。
* `--dry-run` 可在不动文件的前提下预演导出/回写内容。

## 九、注意事项与已知限制

1. 回写前请关闭该 Word 文件与 Excel 工作簿。
2. 请用 **Excel 界面**增删行列：用脚本（如 openpyxl 的 `insert_rows`/`insert_cols`）改工作簿不会搬移合并区与超链接，可能造成错位；工具遇到这类单元格会告警并跳过。
3. 不要修改 A 列表编号、不要删除表块；Word 中新增表格后点「增量导出」追加到「新增表格」，不要重新全量导出，也不要手工往工作簿里拼表块。
4. 工具只处理表格文本与书签：不改正文其它内容，不处理批注、图片、域代码。
5. 若报告被审计软件重新生成（书签与表格变化），重新执行“1-导出表格到Excel”即可重建书签与链接。
6. “合计”行按首列文本以“合计”开头识别；报告写法不同时请手工确认该行位置。

## 十一、标注与占位（链接标注 + 正文占位符）

### 链接标注（高亮标记）

用途：把 Word 里用**高亮**标出的位置集中到 Excel 处理，再一键写回——适合批量替换措辞或插入链接。

1. 在 Word 里用**高亮**标出要处理的位置（任意颜色都算，黄色最直观）。
2. 执行「5-导出标注.py」或界面上的「导出/刷新标注」：工具会给每处插入一个**不可见书签**（`MRK_0001`…）作为定位锚点，并在工作簿里刷新 **`链接标注`** 工作表（与「表格汇总」同一个工作簿）。文档文字与高亮外观都不变。
3. 在 `链接标注` 工作表里填写：

   | 列 | 说明 |
   | --- | --- |
   | 标记 / 书签 / 位置 / 原文 | 工具生成，供你辨认（原文 = 导出时的高亮文字） |
   | **新内容** | 填了就替换该处文字（保留字体、字号）；留空表示暂不改文字 |
   | **链接地址** | 填了就顺带把该处变成可点击超链接（网址或本地文件路径）；留空表示不加链接 |
   | →定位Word | 点击直接跳到 Word 对应位置 |
   | 来源 | `全量` 或 `增量`；既有行不因增量导出改写 |
   | 登记序号 | 工作簿内的登记顺序，新增行延续编号，既有行不变 |

4. 执行「6-同步标注.py」或界面上的「开始同步」：按书签把内容写回 Word。**界面默认勾选「同步后保留高亮（不去色）」**便于复核，取消勾选则同步后自动去色；**命令行默认去色**（黄色 = 待处理、无色 = 已处理），加 `--keep-highlight` 保留高亮。「新内容」「链接地址」为公式时，优先取 Excel 缓存结果，缓存丢失时尝试 `SUM` 与简单四则运算；写回的是计算结果而不是公式文本，无法计算会提示先在 Excel 中打开并保存。
5. 处理情况在表里一目了然：仍带高亮的行是**待处理**；已同步且仍高亮的行在全量刷新时标注**（已处理）**；Word 里连书签都被删掉的行标注**（Word 中已删除）**，只作记录、不再同步。全量导出行号（M01…）按书签保持稳定；增量导出的既有行完全不改，新增行用 XM01、XM02…。
6. **未填口径**：某行「新内容」与「链接地址」都没填时，该处**保留原样不同步**，并逐行警告（只填链接地址视为已填）。

### 正文占位符（{字段名}）

用途：把 Word **正文与页眉页脚（不含表格单元格）**里的 `{字段名}`（如 `{公司名称}`、{审计期间}）集中到工作簿「正文信息」表填写，再一键替换回 Word。该表与「模板生成」共用。

> **「创建Excel」导出时自动生成该表**：Word 正文（含表格/页眉页脚）里有 `{字段名}` 时，导出的工作簿自动带一张「正文信息」表；重复导出（覆盖重建工作簿）会按字段名把上次已填的值带过来，不会丢。没有占位符时该表也照建（空表）。

1. 界面「标注与占位」页 →「正文占位符」tab →「导出/刷新占位符」（工作簿不存在时确认后先完整导出）：扫描正文与页眉页脚的占位符，在工作簿生成/补齐 **`正文信息`** 表（A=字段名、B=填值、C=来源，首行表头），**已填值保留**；表格内占位符不扫描。导出后新加的占位符可用「创建Excel」页「增量导出」只追加到表尾，C 列写「增量」；同名字段共用原值，既有行不动。
2. 在 B 列填值后点「开始同步」（或先「仅预演同步」看替换计划）：只改占位符文字、保留所在 run 的字体格式，跨 run 拆开的占位符也能整体替换。**值按单元格在 Excel 里的显示效果写入**（与表格回写同口径）：日期按数字格式渲染（如 `2026-12-31`、`2026年12月31日`，不会带 `00:00:00`），千分位/小数位/百分比照显示。B 列为公式时优先取缓存结果，其次轻量求值；写回计算结果而不是公式文本，无法计算会提示先在 Excel 中打开并保存。
3. **未填口径**：未填值的占位符**保留原样**并逐条警告；组合回写时若「正文信息」表不存在或一个值都没填，警告并跳过占位符部分（不影响表格/标注）。

命令行等价写法：

```powershell
..\.venv\Scripts\python.exe word_excel_sync.py marks      "报告.docx" --dry-run
..\.venv\Scripts\python.exe word_excel_sync.py marks-sync "报告.docx" --dry-run
..\.venv\Scripts\python.exe word_excel_sync.py marks-sync "报告.docx" --keep-highlight
..\.venv\Scripts\python.exe word_excel_sync.py placeholders      "报告.docx"
..\.venv\Scripts\python.exe word_excel_sync.py placeholders-sync "报告.docx" --dry-run
# 组合同步：表格 + 标注 + 占位符一次写回（默认只同步表格）
..\.venv\Scripts\python.exe word_excel_sync.py writeback "报告.docx" --with-marks --with-placeholders
```

## 十二、删除空白表格

用途：报告里本期不用披露的表格往往留着空壳，用本功能扫描出来、逐表确认后删除。

**空白口径（保守，宁可漏报不误报）**：

* **首列不参与判断**：首列多为行次/项目名称，不算数据；只有 1 列的表除外（首列即全部内容，照常判断）。
* **整表全空**：除首列外所有单元格都没有文字（空白字符不算文字）；
* **仅表头有字**：有文字的行全部是表头行（`w:tblHeader` 标记，未标记时按首行），且表头之外至少还有一行数据区、数据区全空。
* 数据区只有 `—`、`0` 等占位内容的表**不算**空白。

**表标题连带删除**：从表格向前找紧邻的标题段落（跳过空段与日期行）；遇到正文句子、章节大标题（一、/第X节 等）或另一张表即止，不会误认。识别到的标题在预览里显示文字，可单独取消勾选。标题与表格之间的日期行随标题一起删。

**安全机制**：

* 界面「扫描」与命令行默认行为都是**只读**，不改文件；命令行必须 `--pick 编号` 或 `--all` 明确选择后才删除。
* 界面逐表勾选（默认全不勾），删除前弹确认框；写盘前自动备份到 `_backup`。
* 删表/删标题后顺带清理失去配对的本工具书签端点，Word 自带书签不动。
* 普通删除（不勾选可逆）后日志会提醒**重新执行「1-导出表格到Excel」重建工作簿**，再做同步。

**可逆删除与恢复（默认开启）**：

* 勾选「可逆删除」后，Word 里的表照常删，但 **Excel 表块原样保留**，D 列改标 `书签：已删除`，并在锚点行记录 `原位置：Table_xxxx之后` 与 `原标题：…`（新布局 G/H 列、旧布局 F/G 列；原标题仅标题确实被删时记录）。
* 可逆删除**需要工作簿已存在**（先执行一次「导出表格到 Excel」）；候选表在工作簿里找不到对应表块时会报错提示先导出。
* 「同步到 Word」遇到 `已删除` 表块**自动跳过**（日志逐条列出），不会把已删的表又建回去；「导出表格到 Excel」重建工作簿时，`已删除` 表块**原样保留**（内容、合并、公式、原位置/原标题都在），不会被重建冲掉。
* **恢复**：在「删除空白表格」页下方「恢复清单」勾选后点「恢复选中表格」，按表块内容在**原位置**重建 Word 表格与标题（原位置的锚点表已不在时恢复到文档末尾并提醒），自动登记新书签、刷新工作簿元数据，表块标记改回真实书签——之后就是普通表，可正常同步。
* 命令行：`--reversible`（可逆删除）、`--restore 1,3` 或 `--restore all`（按恢复清单编号恢复）、`--excel 路径`（指定工作簿）。

命令行参数：`--pick 1,3`（候选编号）、`--all`（全部候选）、`--keep-caption`（只删表格保留标题）、`--reversible`（可逆删除）、`--restore 编号|all`（恢复）、`--excel`、`--dry-run`、`--force`。

多份报告一次处理：界面「批量删除空表」tab（见第十五节），口径与单文件完全一致。

## 十三、Word 新增内容后的增量导出

用途：保留现有工作簿的行号、编号、已填值与公式引用，只把 Word 中尚未登记的新表格、标注和占位符追加进去。

**操作步骤**：

1. 先执行一次全量「导出表格到 Excel」；之后在 Word 中正常插入表格、增加高亮或正文 `{字段名}`。
2. 在「创建Excel」页点「**增量导出**」，先预演、确认后再正式执行；命令行用 `python -m wesync incremental-export "报告.docx"`，接口用 `api.run_incremental_export(docx)`。
3. 新增表格写入新工作表 **`新增表格`**，编号 `XT01`、`XT02`…，按增量发现顺序排列，永久保留，不随 Word 位置重排。
4. 新增标注追加到 **`链接标注`** 末尾，H 列「来源」写「增量」，编号 `XM01`、`XM02`…；I 列「登记序号」延续原表。既有行号与公式位置不变。
5. 新增占位符追加到 **`正文信息`** 末尾，C 列「来源」写「增量」；同名字段共用 B 列已填值，不重复新增。
6. 回到「同步到 Word」正常同步即可；T 表与 XT 表都支持回写、排序、批量同步、模板生成和空白表可逆删除/恢复。

**关键规则**：

* **全量导出 = 重置**：按当前 Word 重建整个工作簿；会沿用原书签和已填值，但不保证既有行号不变。
* **增量导出 = 只追加**：不更新、删除、移动或重编号既有工作簿行；已有真实表格书签的 Word 表格视为已登记。
* **无新增不写盘**：没有新表格、新标注、新占位符时，Word 与 Excel 字节都不变。
* **表格内排除**：表格单元格内的高亮和占位符不登记，避免与表格数据同步冲突；页眉页脚正文参与，页眉页脚表格排除。
* **重复书签保护**：Word 或工作簿存在重复标注书签、重复表编号时明确报错，不静默覆盖。
* **旧版已停用**：`书签：新增` 表块和「追加新表块」入口已移除；旧工作簿遇到这类块会提示改用增量导出，不会自动建表。

## 十四、按金额列排序（同步时自动重排）

用途：明细表（如往来款、账龄明细）希望按某列金额从大到小排列时，不用在 Excel 里手工排序——设一次，之后每次同步自动排好。

**设置步骤（同步页「排序设置」tab）**：

1. 点「刷新清单」列出工作簿里的表（`新增`/`已删除` 表块不参与）；
2. 选一张表 → 选按哪一列金额排序（下拉列出该表表头文字）→ 选方向（默认**降序**）；
3. 点「保存排序设置」：设置写进该表块**锚点行的「排序：列名 降序/升序」元数据**，随工作簿保存（写前自动备份）；已设置的表在清单里带「已设」标记；
4. 点「清除该表排序」可去掉设置。

**排序规则（每次同步自动应用，Excel 与 Word 一起排）**：

* 只排**数据区**：表头行与「合计」行不动，合计始终在末行；
* 项目名为「**其他**」的行不参与排序，固定放在合计行之前；
* 金额取 Excel 缓存数值（公式取缓存结果）；空值/非数值排在最后；
* 行内公式的行号引用随行移动自动平移；
* **数据区有合并单元格的表跳过排序**并在日志提示（避免搬坏合并结构）；
* 重新执行「导出表格到 Excel」重建工作簿时，排序设置**按书签沿用**，不会丢。

**接口**：`api.list_table_sorts(docx)`（只读列出设置与可选列）、`api.set_table_sort(docx, code=…, column=…, descending=…)`、`api.clear_table_sort(docx, code=…)`；核心实现在 `wesync/sort_rules.py`。

## 十五、批量同步与模板生成

「批量同步」页两个 tab，适合一次处理多份报告；**单份失败/被占用只跳过该份，不影响其他**，每份的状态（✔ 成功 / ✘ 原因）回填到清单「状态」列，日志按 `[i/总数] 文件名` 分段。

**tab 1：多报告批量同步**

1. 点「添加报告」多选 Word 文件，每份自动配**同名工作簿**（`<主名>_表格数据.xlsx`；未找到的标注「将跳过」）；
2. 清单里勾选参与的报告（默认全勾），可「移除选中行」；
3. 「全部仅预演」先看各份改动；「开始批量同步」确认后逐份回写。备份开关默认**不勾**（与单份同步一致），勾选后有改动的文件写前备份。
4. 接口：`api.run_batch_writeback(docx_list, dry_run=…, backup=…)`，返回每份 `{docx, excel, status, reason}`。

**tab 2：模板生成（一个/多个模板 × 多个 Excel → 若干新 Word）**

用途：同一套报告模板配不同底稿数据，批量产出多份新报告；**模板原件与源 Excel 都不改动**（同步在模板副本与工作簿临时副本上进行）。

1. 选**单模板**或**多模板**模式：单模板选一个 Word；多模板可「添加模板」多个，自动编号（模板1、模板2…）；
2. **同步内容三勾选：表格/标注/占位符任意组合**（默认勾表格＋占位符，与原行为一致）；勾「标注」时把「链接标注」表填的新内容/链接同步进生成的 Word，可选保留高亮；不勾「占位符」则不做 `{字段名}` 替换、也不因未填值跳过；
3. 点「添加 Excel 工作簿」加入底稿工作簿；多模板时在清单**「所属模板」列**给每个 Excel 指定模板编号（分组）；
4. 选**输出目录**（默认模板所在目录）；产物命名 `模板名_Excel名.docx`，重名自动加 `_2`、`_3` 后缀，不覆盖已有文件；
5. 「全部仅预演」/「开始生成」。**校验**：工作簿必须是从对应模板导出的（书签能对得上），对不上或未指定模板的该份跳过并提示先导出。
6. 接口：`api.run_template_batch(templates, items, out_dir, dry_run=…, contents=…, keep_highlight=…)`，`items` 每项 `{"excel": 路径, "template": 模板编号}`，`contents` 默认 `("tables", "placeholders")`。

**正文占位符（`{字段名}`）**

模板正文与页眉页脚（不含表格单元格）里可写 `{字段名}`（如 `{公司名称}`、`{报告文号}`），生成时按各工作簿「正文信息」表的值替换，**只改占位符文字、保留所在 run 的字体格式**，跨 run 拆开的占位符也能整体替换。

1. 点「生成正文信息填写表」：按所选模板扫描占位符，给清单里各工作簿加入/补齐一张「正文信息」表（A=字段、B=值，首行表头），**保留已填值**；多模板时按各 Excel 的「所属模板」分组分别生成。此步会修改源工作簿（新增工作表），写前自动备份。
2. 在每份工作簿的「正文信息」表 B 列填值。
3. 「开始生成」时逐份校验（勾选「占位符」时）：占位符**未填齐的该份跳过**并提示缺哪些字段；填齐的才替换并按勾选同步表格/标注。预演会在日志列出 `{字段} → 值` 的替换计划。
4. 模板没有占位符时一切照旧（无需「正文信息」表）。接口：`api.scan_template_placeholders(template)`（只读列字段）、`api.fill_placeholder_sheets(template, workbooks)`（建/补骨架）。

**批量删除空表**（空白表格页第三个 tab）：「添加报告」→「扫描全部」→ 按报告分组逐表勾选（口径、连标题删除与单文件 tab 完全一致）→「删除选中表格」。默认可逆删除（需各报告已生成工作簿）；恢复时到「恢复已删除表格」tab 按报告分别恢复。接口：`api.scan_blank_batch(docx_list)`（只读）、`api.run_blank_batch(items)`。

## 十六、改动留痕、差异比对与备份回滚

面向复核与留痕的三个配套能力，都不改动同步逻辑本身。

**改动留痕清单（同步页勾选「同时导出改动清单」）**

回写后把本次逐格改动导出成一张 Excel 复核底稿，保存在工作簿同目录，命名 `<报告主名>_改动清单_<时间戳>.xlsx`（不覆盖报告与工作簿）。列：表号 / 表名 / 行 / 列 / 项目 / 旧值 / 新值 / 类型；单元格改动逐格记录，增删行、列结构变化、新建表也各记一条。接口：`api.run_writeback(..., changelog=True)`。

**差异比对（同步页「差异比对」tab）**

只读列出 Word 与工作簿当前不一致的单元格（旧值→新值），填到该 tab 内的差异表，**不写任何文件**，供同步前复核；可「导出差异表」存档。本质是把「仅预演」的逐格改动从日志升级成可看的表格。接口：`api.scan_writeback_diff(docx, excel)`（返回记录）、`api.export_diff_report(docx, excel, records)`（导出）。

**备份与回滚（导航「备份与回滚」页）**

每次写盘前自动备份到 `_backup`（带时间戳）的历史版本，在此页 **Word 与 Excel 分开两栏**列出（备份时间 / 文件名 / 大小），选中一行点「恢复」即回滚到该时间点，两者可各自独立回滚。**恢复前先把当前现状再备份一次**，因此回滚本身也可逆。恢复前请先关闭对应文件。接口：`api.scan_backups(docx, excel)`（只读，返回 `{word, excel, word_path, excel_path}`）、`api.run_restore_backup(backup, target)`。
