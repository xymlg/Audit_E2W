# 审计工具箱

在 Qoder Desktop 中处理 Word 与 Excel 的本地审计办公插件。当前版本：**v1.11.1**。

插件把桌面版的核心能力集中在一个界面中，包括创建 Excel、同步 Word、差异比对、链接标注、正文占位符、书签维护、空白表删除与恢复、批量同步、模板批量生成以及备份回滚。

## 运行环境

- Qoder Desktop，Windows 10/11 64 位。
- 内置 Windows 本地引擎，**不支持 macOS**。
- 不需要另外安装 Python 或 Node.js；MCP 服务使用 Qoder 自带 Node.js 运行。
- 打开和编辑生成的 Word/Excel 文件需要 Microsoft Office。
- 支持 `.docx` / `.docm`、`.xlsx` / `.xlsm`；写回 `.xlsm` 时保留 VBA。

## 安装

### 本地 ZIP 安装

1. 打开 Qoder Desktop 左侧 **扩展**。
2. 进入 **插件 → 添加插件 → 导入插件 / 上传 Plugin**。
3. 选择 `Audit_E2W_qoder_v1.11.1.zip`。
4. 安装后在 **已安装** 中启用“审计工具箱”。

本地安装只在当前设备生效，不会自动发布到公共市场。

### 公共市场安装

如果公共市场对你所在账号和地区可用，可在 **扩展 → 插件** 中搜索“审计工具箱”，核对发布者和权限后安装。市场是否可见、是否允许发布，以当前客户端和发布中心页面为准。

## 打开与首次检查

1. 从插件的全局或会话入口打开“审计工具箱”。
2. 右上角应显示 **本地引擎 1.11.1 已就绪**。
3. 如提示找不到引擎或版本不一致，请重新安装完整的插件 ZIP，不要只复制 `server.mjs`。
4. 选择左侧任务，按“选择文件 → 操作选项 → 预演 → 确认执行”的顺序操作。

## 典型流程

### 1. 从 Word 创建 Excel

1. 选择 **创建 Excel**。
2. 选择 Word 报告；Excel 路径默认按同名报告生成，也可以手选。
3. 建议先勾选 **仅预演**，确认没有警告。
4. 正式创建后，工作簿固定包含“表格汇总”“链接标注”“正文信息”三个工作表。
5. 后续用 Excel 界面修改明细、增删行列或填写标注和占位符，保存并关闭 Excel。

### 2. 同步回 Word

1. 选择 **同步到 Word**，再次选择同一份 Word 和工作簿。
2. 选择同步内容：表格、链接标注、正文占位符可以任意组合。
3. 先 **仅预演** 或使用 **差异比对** 核对。
4. 正式执行前确认文件列表和备份选项，再点 **确认并执行**。
5. 同步后检查右侧日志和结果；失败时先关闭 Word/Excel，再按日志或备份恢复。

### 3. 标注与占位符

- **导出 / 刷新标注**：把 Word 高亮位置写入“链接标注”表。
- **同步标注到 Word**：把新内容和可选链接写回高亮位置。
- **补齐占位符工作表**：扫描 `{字段名}`，生成或补齐“正文信息”表。
- **同步占位符到 Word**：按填写值替换占位符，保留字体和版式。

## 让 Agent 帮你干活

插件内置 `audit-word-excel` Skill。启用插件后，可以直接在对话里交代任务，不必先打开操作页面。Agent 会按“检查文件和引擎 → 读取能力目录 → 预演或差异检查 → 说明改动并确认 → 正式执行 → 核验结果”的顺序处理。

`audit_capabilities` 提供 28 项操作的必填参数、默认值、预演支持和示例；任务完成后，`audit_task_status.summary` 会汇总输出文件、改动数量、备份、警告及批量成功/跳过/失败情况。批量任务即使总状态为 `succeeded`，Agent 也会检查 `outcome=partial` 和失败清单。

可以直接这样说：

- “把 `E:\报告\审计报告.docx` 导出成 Excel，先预演。”
- “Excel 改好了，只把表格同步回 Word，先告诉我有什么差异。”
- “把表格、标注和正文占位符全部同步回 Word。”
- “用 `E:\报告\模板.docx` 和 `E:\报告\底稿.xlsx` 生成一份新 Word，不要覆盖原件。”
- “批量同步 `E:\报告\待处理` 里的 Word 和同名 Excel，失败的单列出来。”

安全约定：

- Agent 先预演或只读检查，不会把“先看看”当成写盘指令。
- 删除、覆盖和恢复备份前会说明范围并等待确认。
- 单模板生成只创建新 Word，不覆盖模板原件和源 Excel。
- 文件被占用时先提示关闭文件，不默认强制保存。
- 完成后汇报输出文件、改动数量、警告、备份位置和建议复核项。

如果 Agent 看不到 `audit_*` 工具，先确认插件已安装并启用，再重新加载插件或新建会话。插件服务显示“已连接”但工具数为 0 时，通常是工具可见性或插件版本加载问题。

## 跨平台 Agent Skill

通用 Skill 源位于项目 `agent_skills/audit-word-excel/`，Qoder 打包时会自动同步到本插件。WorkBuddy 和 DSH 使用独立 Skill ZIP，通过同一套业务规则和本地引擎脚本接入，不包含 Windows 引擎二进制。

- WorkBuddy：上传对应 Skill ZIP 前，本机仍需安装审计工具箱，并允许 Agent 使用 Bash 和本地文件。
- DSH：把 ZIP 解压到项目 `.dsh/skills/` 或用户级 `<dshHome>/skills/`，同样需要本地引擎和文件权限。
- Qoder：优先使用插件 MCP 工具；本地脚本只是 MCP 不可用时的备用通道。

详见 Skill 内的 `references/platforms.md`。跨平台包不代表已完成 WorkBuddy 或 DSH 的市场审核。

## 数据与安全

- 报告内容只在本机处理，**插件不联网、不上传报告内容**。
- 只处理用户主动选择的本地文件；查询任务只读，写盘任务显示确认。
- 默认在写盘前备份到原文件旁的 `_backup` 文件夹。
- 执行前请关闭对应 Word/Excel 文件；文件被占用时会提示，不要随意跳过占用检查。
- 公式单元格按 Excel 显示结果写回。如果公式没有缓存结果，请先在 Excel 中重算并保存。
- 不要在插件包、市场介绍或截图里放真实报告、客户名称、账号、密码或 API Key。

## 常见问题

### 右上角提示引擎不可用

确认安装的是完整 ZIP，且 `engine/审计工具箱引擎.exe` 与 `engine/_internal` 均存在。重新安装与当前插件版本一致的包。

### 文件选择器不可用

直接粘贴完整的 Windows 绝对路径，例如 `E:\报告\审计报告.docx`。相对路径不会被接受。

### 同步后公式显示为公式文本或没有结果

公式单元格应写回计算结果。若 Excel 尚未计算，先在 Excel 中打开工作簿、完成重算并保存，再重新同步。

### 表格被删除或定位错位

先查看日志和 `_backup`，不要直接重新导出覆盖已编辑工作簿。可用“查看可恢复表格”或“重建/迁移书签”处理。

### 如何更新或卸载

- **更新**：安装版本号更高的新 ZIP；审核中的市场版本不会自动替换当前线上版本。
- **卸载**：在 Qoder 的 **扩展 → 插件 → 已安装** 中管理“审计工具箱”。卸载前自行保存需要保留的报告和工作簿。
