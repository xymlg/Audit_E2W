description: 只读检查报告差异、空白表、模板字段或格式候选，不修改文件
---
使用 `audit-word-excel` Skill 完成只读检查任务。

本次目标：按用户要求检查差异、空白表、模板字段、格式方案或候选标题。本命令只读，不执行修复、删除、恢复或格式应用。

1. 调用 `audit_engine_status`，确认引擎可用且版本一致。
2. 调用 `audit_capabilities` 核对只读 operation 和参数，再用 `audit_query` 检查；不得改用 `audit_run` 写盘。
3. 报告候选编号、差异位置、缺失字段、警告和截断情况；格式候选只使用本地返回的候选及有限上下文，不上传整篇报告。
4. 用户后续要求修复时，先结束本次只读检查，回到 Skill 的预演与确认流程；先预演或只读检查，写盘前等待用户明确确认，不在本命令自动执行。
5. 用 `audit_task_status` 等待检查结束，说明结果和需要补充的文件或决定。

斜杠指令不是写盘确认；不得自动设置 `confirmed=true`、`force=true` 或关闭备份。不要用 Bash 直接调用引擎。
